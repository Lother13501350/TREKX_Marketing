旅遊規劃混亂指數調查

調查目的

用真實數據支持 ChillOut 的問題假設：現代旅客不缺旅遊靈感，缺的是把社群靈感整理成可執行行程。

Google Form 題目

題型題目選項/說明
單選你過去一年出國幾次？0 次 / 1 次 / 2-3 次 / 4 次以上
單選你最常去哪裡找旅遊靈感？Instagram / TikTok / 小紅書 / YouTube / Google / 朋友推薦 / 旅行社
複選你排行程會用哪些工具？Google Maps / Notes / Excel / Notion / ChatGPT / 旅遊 App / 紙本
量表你覺得排行程麻煩程度？1 非常簡單 - 5 非常痛苦
數字你通常會收藏多少個景點才開始排行程？開放填答
單選你最卡在哪一步？找景點 / 安排動線 / 查交通 / 跟旅伴討論 / 做行程表 / 分享給別人
量表如果 App 可把 IG 景點變成行程，你願意試嗎？1 完全不願意 - 5 非常願意
單選你最想先用在哪種旅行？日本 / 韓國 / 台灣週末 / 東南亞 / 歐洲 / 親子 / 情侶 / 朋友
開放你理想中的 AI 旅遊 App 要幫你做到什麼？開放填答
開放你最不信任 AI 排行程的地方是什麼？開放填答

樣本目標

  • 第一階段：100 份，作為產品與文案修正。
  • 第二階段：300 份，可做成社群圖卡與 PR 報告。
  • 第三階段：1,000 份，可包裝成年度白皮書。

分析維度

  1. 1. 不同年齡/旅行頻率的痛點差異。
  2. 2. IG/TikTok 使用者是否更需要 ChillOut。
  3. 3. 最常用工具與最大斷點。
  4. 4. 最有意願嘗試的目的地。
  5. 5. 對 AI 不信任的主要原因。

報告標題候選

  • 台灣自由行規劃混亂指數
  • 為什麼大家收藏很多景點，卻還是排不出行程？
  • 社群旅遊靈感時代：IG 收藏如何變成真正的旅行？
