低預算投放測試計畫

原則

月預算 NT$0-10,000，不追求大規模投放。投放只做兩件事：

  1. 1. 找出哪個訊息能讓人下載後生成行程。
  2. 2. 放大已經在自然流量證明有效的素材。

Meta Ads 結構

  • Campaign：ChillOut Activation Test
  • Ad Set A：台灣 20-35，興趣日本旅遊/韓國旅遊/自由行
  • Ad Set B：台灣 20-35，興趣 Instagram/TikTok/咖啡廳/旅遊攝影
  • Ad Set C：台灣 25-44，興趣親子旅遊/家庭旅遊
  • Daily Budget：每組 NT$100-200
  • Duration：3 天初篩，7 天決策

Apple Search Ads 結構

  • Brand：ChillOut
  • Generic exact：AI travel planner、travel planner、itinerary planner
  • Chinese exact：旅遊規劃、自由行、行程規劃、AI 行程
  • Destination exact：東京自由行、首爾自由行、日本行程
  • Daily Budget：NT$200 起

停止條件

  • 3 天無下載：停止素材。
  • 7 天有下載但無生成行程：停止受眾或改 onboarding。
  • CPI 可接受但 activation 很差：不放大。

放大條件

  • 有明確生成行程。
  • 留言顯示使用者理解產品。
  • App Store page conversion 沒有下降。
  • 每次加預算不超過 30%。
