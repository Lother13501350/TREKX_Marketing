Commercial rebuild report

100 個旅行小工具，從概念庫重做成 100 個獨立產品。

本報告定義這批小工具的重做標準、驗收方式、差異化規則與正式執行方向。核心修正：不能再用同一套模板換文字，每個工具都必須有自己的問題、玩法、介面、資料輸入、結果邏輯、分享機制與 App 導流。

每個工具獨立 URL 每個工具獨立 UX 每個工具獨立演算法 每個工具獨立視覺語言 單一主題色 每個工具導回 ChillOut

一、目前問題診斷

問題影響重做要求
100 個工具共用同一套互動模板使用者會覺得只是換標題，沒有真的工具價值。每個工具必須有自己的操作模型，例如清單整理、投票、地圖、輪盤、合約、計算器、故事生成、路線排程等。
結果卡太空泛無法讓使用者相信工具有用，也不會願意分享。結果必須包含可執行輸出：分類、路線、分數、決策、文案或 prompt。
視覺像資料庫，不像產品不適合拿去做社群、廣告或創作者合作。每個工具都要有主畫面、工作區、輸出區與可截圖的分享結果。
沒有商業化驗收做完無法判斷能不能拿去投放。每個工具完成時都要通過：可理解、可操作、可輸出、可分享、可導流、可追蹤。

二、商業化完成標準

1. 使用者 5 秒理解

首屏要清楚說明這個工具解決什麼痛點，並直接顯示主要操作，不藏在長文後。

2. 真正可操作

至少有 3 種有效輸入或互動，輸入會改變結果，而不是永遠產生同一張卡。

3. 結果可執行

結果必須能讓使用者下一步行動，例如整理收藏、排出路線、做出選擇、產出合約或分享文案。

4. 可分享

每個工具要有可複製文案或可截圖區域，文案自然帶回 ChillOut。

5. 獨立風格

不能只換顏色。版面結構、互動方式、結果形式都要符合工具本身；每個工具只使用一個主題色與中性色，避免花俏雜訊。

6. 導流可追蹤

App Store 連結使用對應 ct 參數，例如 ct=tool_save_sprint_route。

三、100 個工具的重做策略

重做順序不是一次套版產生，而是逐一產品化。每完成一個工具，就留下該工具的 PRD、功能說明、QA 截圖與可投放角度。總頁維持 100 個獨立連結，但每個連結背後會逐步替換成 bespoke 工具。

目前基礎修正：所有尚未 bespoke 的工具頁已改成單一主題色、中性色介面、6 種版面骨架與單色 SVG 素材，先移除多色、深色、模板感過重的問題。接下來仍會逐一替換成完全獨立的玩法與演算法。

四、T001 IG 靈感急救室 PRD

主要功能：把使用者散落的 IG 收藏、景點筆記、朋友傳來的店名，直接整理成一條今天可以先走的路線與第一版 ChillOut prompt。

核心使用者：IG 收藏很多、截圖很多、出發前仍然不知道怎麼排的人。

核心流程：貼上收藏 → 選目的地與旅行感覺 → 產生第一版路線 → 複製分享文案或丟進 ChillOut。

商業用途：可做短影音「我把 30 個 IG 收藏變成一天路線」、Threads 互動文、Dcard 實用工具文、SEO 頁與廣告 landing page。

五、T001 驗收清單

  • 可以貼上多行 IG/景點素材，沒有素材時提供示範資料。
  • 使用者只需要一個輸入框、目的地與旅行感覺，不再進入複雜看板。
  • 會產生具體時間線、暫不排清單、分享文案與 ChillOut prompt。
  • App Store 導流含工具專屬 ct 參數。
  • 瀏覽器實測截圖確認視覺與互動可用。

六、T002 三張截圖路線工坊 PRD

主要功能：把三張旅遊截圖代表的地點，轉成三個路線節點，並依類型與起始時間排出可出發的半日路線。

核心使用者：相簿裡存了一堆旅遊截圖，但不知道這些點能不能串在一起的人。

核心流程：輸入三個地點 → 選目的地與起始時間 → 產生半日順序 → 複製分享文案或丟進 ChillOut。

商業用途：可做「三張截圖變一趟旅行」短影音、相簿整理互動、IG 限動問答、SEO 頁與創作者貼文模板。

八、T003 旅遊創作者路線 Remix PRD

主要功能：貼上創作者推薦路線，依使用者自己的預算、步調、想避開的雷點，把原路線改成更適合自己的版本。

核心使用者：看旅遊創作者內容會心動，但擔心照抄後太貴、太擠、太趕或不適合自己的人。

核心流程：貼上創作者路線 → 設定預算/步調/避開項目 → 工具標記保留、替換、升級、降級 → 產生 Remix 時間線、分享文案與 ChillOut prompt。

UI 規範更新：每個工具只使用一個主題色與中性色。T003 主題色為紫色，搭配深色中性色；背景使用 Unsplash 授權旅遊素材作為情境圖。

九、T004 爆紅景點值得嗎 PRD

主要功能：輸入爆紅景點、期待值、人潮耐受、排隊成本與替代意願，判斷這個點應該值得去、改時段去，還是改找同氛圍替代點。

核心使用者：看到 IG、TikTok 或小紅書爆紅景點心動，但又怕排隊、踩雷、浪費半天的人。

核心流程：輸入景點 → 調整四個滑桿 → 取得分數與決策 → 複製 ChillOut prompt 生成附近半日路線。

趨勢依據：對齊 2026 旅遊趨勢中的 detour/destination dupe、過度觀光避讓、個人化旅行決策與社群種草後的行程轉換需求。

十、T005 收藏斷捨離 PRD

主要功能：把一長串旅行收藏逐張做「保留、備用、刪掉」決策，清出真正能進行程的清單。

核心使用者：IG 收藏很多、但每次排程都被收藏數量拖住的人。

核心流程：貼上收藏 → 每張卡片快速判斷 → 形成三桶清單 → 複製 ChillOut prompt 生成行程。

商業用途：適合做「清掉 100 個旅行收藏」短影音、限動互動挑戰、Dcard 工具文與社群留言互動。

十一、T006 景點心情分艙 PRD

主要功能：把一堆景點先依旅行心情分成「興奮、放空、拍照、吃喝」四艙，再輸出每天主旋律與 ChillOut prompt。

核心使用者：景點很多但不知道怎麼分天的人，尤其是從 IG、截圖、朋友推薦混在一起開始排程的人。

核心流程：貼上景點 → 逐點分艙或自動分剩下 → 產生四艙結果 → 產生 Day 1/2/3 主旋律 → 丟進 ChillOut 排完整路線。

商業用途：適合做「不要先照地圖排，先照心情排」短影音、Threads 互動題、Dcard 工具文與 SEO 頁。
